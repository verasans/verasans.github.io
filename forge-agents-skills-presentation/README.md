# Agents and skills on the Forge: presentation

A self-contained, responsive HTML deck. Open `index.html`, or embed it:

```html
<iframe src="https://your-site/forge-agents-skills/index.html"
        title="Agents and skills on the Forge"
        style="width:100%; aspect-ratio:16/9; border:0" allow="fullscreen" loading="lazy"></iframe>
```

- Keep `index.html` and the `assets/` folder together. There are no external requests.
- Slides scroll vertically. Arrow keys, Page Up/Down, the dots on the right and the up/down buttons move between them, and `index.html#7` opens slide 7.
- The images come from `../capture.mjs` and the clips from the demo videos in `docs/demos/`. Rebuild them with `sh ../build-assets.sh`.
